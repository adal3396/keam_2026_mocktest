# KEAM 2026 Mock Test Platform

An online mock test platform for KEAM 2026 entrance exam preparation, built with React, Vite, Supabase, and Firebase Auth.

## Features

- Timed mock tests with auto-submission
- Admin dashboard for exam management
- Real-time leaderboard
- LaTeX math rendering for science questions
- Anti-cheating: auto-submit on tab/window switch

## Getting Started

```bash
npm install
npm run dev
```

Create a `.env` file based on `.env.example` with your Supabase and Firebase credentials.
